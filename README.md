
# Pensumbørs 📚

Pensumbørs is a marketplace where students in Norway can buy and sell used 
textbooks. Students can search by course code, filter by price and condition, 
and post their own listings.


## Why I built it

Textbooks are expensive, and many students only use a book for one semester. 
Selling used books today usually happens in scattered Facebook groups or 
general marketplaces, where it is hard to find the right book for a specific 
course. Pensumbørs makes it easy to search by course code and find cheap 
used books from other students.

## Features

- Search for books by course code or title
- Filter by price, condition and city, and sort by newest or cheapest
- Post a new listing with title, author, course code, price and condition
- Mark listings as reserved or sold
- Save favourites
- Listings and favourites are saved in the browser, so they survive a reload
- Works on both mobile and desktop

## How it was built

This app was made for a university assignment about vibe coding: building an 
app by describing it in natural language and letting AI write the code. I 
built it with Claude, adding one feature at a time and testing after each step.

## Technical details

- A single HTML file with all HTML, CSS and JavaScript included
- Data is stored with the browser's localStorage (no server or database)
- Hosted on GitHub Pages
- All listings in the app are made-up sample data

## Limitations and ideas for the future

- There are no user accounts, so anyone using the same browser can edit 
  any listing
- Data is only saved in your own browser, so other people cannot see 
  listings you post
